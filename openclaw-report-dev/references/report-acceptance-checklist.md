# ReportStudio v2.0 验收清单

## 功能验收
- [ ] 自然语言可创建可预览报表
- [ ] 支持导出 PDF/XLSX/DOCX/PPTX
- [ ] 模板可保存、复用、参数重映射
- [ ] Preview Studio 四种模式可切换
- [ ] 拖拽排版/图表切换/样式编辑/参数编辑可用
- [ ] 撤销/重做支持 50 步
- [ ] 自动暂存 30s 周期可恢复
- [ ] 自动洞察可生成 3-5 条关键发现
- [ ] 异常可归因下钻
- [ ] 评审流程完整闭环
- [ ] 版本对比与回滚可用
- [ ] 血缘追溯与影响分析可用
- [ ] RBAC 与行级权限生效
- [ ] 调度按 cron 执行，失败重试可用

## 安全验收
- [ ] 下载链接签名 + 过期失效
- [ ] 关键操作审计可查（创建/编辑/导出/下载/改权）
- [ ] 敏感字段按角色脱敏
- [ ] 未授权用户不可访问资源
- [ ] 原始数据按策略清理，不长期落盘

## 性能验收
- [ ] <=1万行预览 P50 <= 5s
- [ ] 编辑响应 P50 <= 2s
- [ ] 导出 P50 <= 30s
- [ ] 自动暂存成功率 >= 99.9%
- [ ] 支持 100 并发报表任务
