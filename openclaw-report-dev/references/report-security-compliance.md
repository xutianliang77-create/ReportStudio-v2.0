# 安全与合规模板（ReportStudio）

## 1. 数据最小化
- 仅在生成链路中处理原始数据。
- 任务结束后清理临时原始数据缓存。

## 2. 数据脱敏
默认支持：
- 手机号：`138****1234`
- 邮箱：`z***@company.com`
- 身份证：`110***********1234`
- 银行卡：`****1234`
- 地址：仅保留省市

并支持按角色配置字段级脱敏。

## 3. 下载安全
- 签名下载链接（默认 24h 过期）
- 下载审计记录（用户、IP、时间、文件）
- 支持文档水印（用户/时间/来源）

## 4. 权限控制
- RBAC（viewer/user/editor/admin）
- 行级过滤（如 `region = '华东'`）
- 字段可见性控制（敏感指标隔离）

## 5. 风险提示
当出现以下情况时，必须在报表或导出说明中提示：
- 样本不足
- 缺少同比/环比基期
- 字段识别不确定
- 异常值影响较大
- 数据时效性滞后
